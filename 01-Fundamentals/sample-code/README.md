# サンプルコード置き場

各回の教材から参照する、まとまった分量のコードを置く場所です。

## `bme280.py`

`06_I2CとSPIでセンサと話す.md`から参照している、BME280(温湿度・気圧センサ)用のドライバです。SpaceAcademyが独自に作成した、教育向けのSPI/I2C両対応ライブラリです。

- サードパーティ製のライブラリに依存せず自作している理由:「レジスタを読み書きする処理」がそのまま読めるようにするためです。市販ライブラリのようにブラックボックス化しないことで、興味のある生徒が中身を覗けるようにしています。
- I2CとSPIを同じファイル(同じ`BME280`クラス)で兼用しています。コンストラクタに`i2c=`を渡すか`spi=`(+`cs=`)を渡すかで、内部のレジスタ読み書き方法(`_I2CBus` / `_SPIBus`)だけが切り替わり、校正計算などの本体ロジックは共通です。
- 気温・気圧・湿度への変換式は、Bosch社公式のBME280データシート(4.2.3節)に記載されている補正アルゴリズムをそのまま実装しています。

### 生徒への配布方法

Thonnyで`bme280.py`を開き、**ファイル→名前をつけて保存→Raspberry Pi Pico**でPico W本体に`bme280.py`として保存してもらってください(`main.py`と同じ階層)。以後、教材内のコードは`import bme280`だけで使えます。

## 確認課題1:点滅間隔を引数にする

```py
# led_utils.py に追記
def blink_led_v2(pin_num, times, interval):
    led = Pin(pin_num, Pin.OUT)
    for i in range(times):
        led.value(1)
        time.sleep(interval)
        led.value(0)
        time.sleep(interval)
```

```py
# main.py
import led_utils

led_utils.blink_led_v2(15, 3, 0.1)
```

### 指導のポイント

- `blink_led`との違いは引数が1つ増えただけであることに気づかせてください。「引数を増やす=関数をもっと柔軟にできる」という感覚が今日のねらいです。
- `interval`のデフォルト値を持たせる(`def blink_led_v2(pin_num, times, interval=0.3):`)ところまで踏み込めると発展的です。余裕があれば紹介してください。

## 確認課題2:値を返す関数

模範解答例(どちらか、または生徒が考えたものでよい):

```py
def bigger(a, b):
    if a > b:
        return a
    else:
        return b

def seconds_to_min_sec(total_seconds):
    minutes = total_seconds // 60
    seconds = total_seconds % 60
    return minutes, seconds  # タプルとして2つの値を返す
```

### 指導のポイント

- 「動作をする関数」(`blink_led`)と「値を計算して返す関数」(`add`・`bigger`)の違いを言語化できているかを確認してください。
- `return`の後にコードを書いても実行されない(`return`で関数の実行がそこで終わる)ことに気づく生徒がいれば、積極的に取り上げてください。

## 発展課題:モーター・タクトスイッチの関数化

```py
# led_utils.py とは別に motor_utils.py などを作ってもよい
from machine import Pin
import time

def motor_on(pin_num, seconds):
    motor = Pin(pin_num, Pin.OUT)
    motor.value(1)
    time.sleep(seconds)
    motor.value(0)

def is_button_pressed(pin_num):
    button = Pin(pin_num, Pin.IN, Pin.PULL_DOWN)
    return button.value() == 1
```

### 指導のポイント

- モーターについては、[03_マイコン入門とLチカとモーター.md](../03_マイコン入門とLチカとモーター.md)「3.6 モーターを止めたあと、PCと繋がらなくなったら」の内容を思い出させてください。関数の中で`motor.value(0)`を忘れると、前回と同じ症状が起きます。
- タクトスイッチは[04_タクトスイッチとデジタル入力.md](../04_タクトスイッチとデジタル入力.md)のプルダウン抵抗の設定を思い出す必要があります。忘れている生徒には該当ページを見返させてください。

## picozeroとの比較

`picozero.Button`は`is_pressed`というプロパティ、`when_pressed`/`when_released`というイベントハンドラを持っています。自作の`is_button_pressed`(呼ぶたびに読みに行く方式)との違い、特に「呼ばれるまで待つ」動き方(イベント駆動)は今日の範囲を超えるので、深入りせず「便利な書き方が用意されている例」として紹介する程度で十分です。

## 宿題:picozeroのクラス探し

想定される答えの例:

| クラス | 用途 | CanSatでの用途例(生徒の発想を尊重してください) |
| --- | --- | --- |
| `Button` | ボタン・スイッチの読み取り | 着地検知スイッチ、モード切り替えスイッチ |
| `Motor` | DCモーターの正転・逆転・速度制御 | パラシュート展開機構、ホイールの駆動 |
| `Buzzer` | ブザーを鳴らす | 電源投入音、エラー通知音 |
| `DistanceSensor` | 超音波距離センサ | 着地高度の推定 |
| `Servo` | サーボモーターの角度制御 | カメラの向き調整、展開機構 |

正解を1つに絞る必要はありません。「名前から用途を推測し、CanSatに結びつけて考える」という思考の練習が目的です。次回冒頭で2〜3人に発表してもらうと良いでしょう。
